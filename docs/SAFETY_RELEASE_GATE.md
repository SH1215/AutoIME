# Safety Release Gate for v0.1.0-alpha

AutoIMEは便利さよりも、ユーザーの入力内容・文書・ファイルを壊さないことを優先します。

## 公開前の基本原則

1. **ファイルを直接操作しない**
   - AutoIMEはファイルの保存、削除、上書き、移動を行わない。
   - 対象は「現在の入力欄にある直前の入力文字列」のみに限定する。

2. **削除前に対象文字列を再確認する**
   - 変換対象のASCII文字列がカーソル直前に存在することを確認する。
   - 1文字でも一致しない場合は何もしない。

3. **不確実なら何もしない**
   - 日本語ローマ字かどうかの判定に自信がない場合は変換しない。
   - 誤変換より未変換を優先する。

4. **危険な入力欄では動作しない**
   - パスワード欄
   - 認証情報入力欄
   - Terminal / PowerShell / cmd
   - VS Codeなどの開発環境
   - その他、誤変換が重大な影響を与える環境

5. **キー入力を広範囲に奪わない**
   - Ubuntu版ではSpace、Ctrl、Shift、矢印キー等のグローバルgrabを行わない。
   - Windows版でも通常のキー操作への干渉を最小限にする。

6. **即時停止できること**
   - AutoIME ON/OFFを簡単に切り替えられる。
   - 異常時に即停止できる。

7. **入力内容を外部送信しない**
   - 入力文字列はローカル判定を基本とする。
   - テレメトリを追加する場合は明示的なオプトインとする。

## v0.1.0-alpha 公開条件

以下を満たすまでReleaseを公開しない。

### 基本動作
- [ ] `nihongo` のような対象が正しく救済される
- [ ] 2回、3回と連続して動作する
- [ ] AutoIME OFF時に通常入力へ干渉しない

### データ保護
- [ ] 直前の対象文字列以外を削除しない
- [ ] 確定済みの前の文章を削除しない
- [ ] 改行、段落、他の入力欄へ影響しない
- [ ] クリップボード内容を破壊しない

### キー操作保護
- [ ] Ctrl+C / Ctrl+Vに干渉しない
- [ ] Ctrl+Zに干渉しない
- [ ] 矢印キーに干渉しない
- [ ] Enter / Tab / Escに干渉しない

### 機密入力保護
- [ ] パスワード欄で動作しない
- [ ] Terminal / PowerShell / cmdで動作しない
- [ ] 開発環境で不用意に動作しない

### アプリ互換性
- [ ] Windows メモ帳
- [ ] Chrome / Edge / Firefox
- [ ] Microsoft Word
- [ ] LibreOffice Writer
- [ ] Gmail / Webメール
- [ ] ChatGPT入力欄

### 長時間安定性
- [ ] 1時間以上常駐しても入力異常がない
- [ ] ON/OFFを繰り返しても問題ない
- [ ] OSログイン後の自動起動で問題ない

## 公開方針

Public Alphaでは「誤変換がゼロ」であることよりも、
**ユーザーの大切なデータを消さない・壊さないこと**を最優先する。
