# Public Alpha テスト計画

## 基本テスト
- [ ] `nihongo` → 日本語
- [ ] `koreha` → これは
- [ ] `watashiha` → 私は
- [ ] 2回、3回と連続して使える
- [ ] 確定済みの前の文章を消さない
- [ ] AutoIME OFF時は通常入力と同じ

## 安全性
- [ ] パスワード欄で作動しない
- [ ] Terminal / PowerShell / cmdで作動しない
- [ ] Ctrl+C / Ctrl+Vに干渉しない
- [ ] 矢印キーに干渉しない
- [ ] クリップボードを破壊しない
- [ ] 長時間常駐後も正常
